projeto em andamento  Galeria de Arte Digital

Uma plataforma web desenvolvida para comercializar pinturas e promover o acesso democrático à arte para todos, conectando artistas independentes a entusiastas e compradores.

 Sobre o Projeto

Este projeto nasceu do desejo de quebrar as barreiras do mercado de arte tradicional. A plataforma funciona tanto como uma vitrine de exposição cultural quanto como um e-commerce simplificado, permitindo que qualquer pessoa conheça novas obras e adquira pinturas originais de forma acessível.

 Objetivos Principais:
Comercialização: Facilitar a venda de pinturas de artistas independentes.
Acessibilidade: Criar uma interface inclusiva e de navegação simples para aproximar o público geral do mundo das artes.
Portfólio Virtual: Servir como um espaço de exposição permanente para as obras.

Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais (Vanilla), garantindo leveza e total controle sobre a aplicação:
HTML5: Estruturação semântica das páginas para melhor acessibilidade e SEO.
CSS3: Estilização responsiva, utilizando conceitos modernos de layout (Flexbox/Grid) para valorização visual das obras.
JavaScript (ES6+):** Manipulação dinâmica do DOM para interatividade da galeria, filtros de busca e gerenciamento do carrinho de compras.

## Práticas de Código Limpo (Clean Code) 

A arquitetura deste projeto foi guiada por boas práticas de desenvolvimento para garantir que o código seja legível, modular e de fácil manutenção:
Semântica Clara:** Uso rigoroso de tags HTML5 adequadas (`<main>`, `<section>`, `<article>`) melhorando a leitura do código e a acessibilidade.
Separação de Responsabilidades:** Divisão clara entre a estrutura (HTML), a apresentação (CSS) e o comportamento/lógica de negócios (JavaScript).
Nomenclatura Significativa:** Variáveis, funções e classes com nomes autoexplicativos em vez de comentários excessivos.
Funções de Responsabilidade Única:** Scripts JavaScript divididos em pequenas funções focadas em resolver apenas um problema por vez.
CSS Organizado:** Uso de metodologias de classes organizadas para evitar acoplamento e seletores excessivamente longos.

Funcionalidades Principais

Galeria Responsiva:** Visualização limpa e otimizada das pinturas em qualquer tamanho de tela (celular, tablet ou PC).
Filtros de Obras:** Busca facilitada por categoria, artista, preço ou estilo artístico através de JS dinâmico.
Área de Compra/Interesse:** Interface intuitiva para simular a compra ou entrar em contato para adquirir a obra.
